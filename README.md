# Homelab

Welcome to my Homelab repository! This project serves as my personal playground and testing environment. 

The primary goal of this homelab is to gain hands-on experience, test new technologies, and simulate enterprise environments on a smaller scale.

## Infrastructure & Hardware

My current setup runs on the following hardware and base OS:

*   **Server / Host:** Lenovo ThinkPad T480
*   **CPU:** Intel Core i5-8250U
*   **RAM:** 64 GB
*   **Storage:** 1 TB
*   **Operating System:** Ubuntu Server 26.04 LTS
*   **Network:** Basic router (static IP)
